Warm-Up Question

Which of these are “nested” structures?

A. ((()))
B. if (x) { while(y) { } }
C. abababab
D. <html><body></body></html>
A, B, and D are nested. CFGs are good at describing nested structures.

What is a Grammar?

A grammar is a set of rules for building valid strings or sentences.

Human language

Sentence → Subject + Verb + Object

The student writes code.

Computer language

Expression → Number + Operator + Number

5 + 3

Simple idea: Grammar tells us what is allowed and what is not allowed.

Context-Free Grammar: Main Idea

A Context-Free Grammar or CFG describes languages where one variable can be replaced by a pattern, regardless of where that variable appears.

S → aSb S → ε

This grammar generates strings like:

εabaabbaaabbb

Formal Definition of CFG

A CFG is usually written as a 4-tuple:

G = (V, Σ, R, S)

V

Variables / non-terminals

Σ

Terminals / actual symbols

R

Rules / productions

S

Start symbol

Parts of a CFG

PartMeaningExample
VariableA placeholder that can still be expandedS, A, B, Expr
TerminalFinal symbol that appears in the output stringa, b, 0, 1, +, id
ProductionA replacement ruleS → aSb
Start SymbolWhere generation beginsS

Example 1: Balanced a’s and b’s

S → aSb | ε

This means:

  • Use S → aSb to add one a at the front and one b at the end.
  • Use S → ε to stop.

Language generated: L = { aⁿbⁿ | n ≥ 0 }

Guided Derivation: Generate aabb

A derivation shows the step-by-step use of grammar rules.

S ⇒ aSb ⇒ aaSbb ⇒ aaεbb ⇒ aabb
Ask: How many times did we use S → aSb? Answer: 2 times, so we produced 2 a’s and 2 b’s.

Parse Tree: Visual Form of Derivation

A parse tree shows how a string is produced from the start symbol.

S / | \ a S b /|\ a S b | ε

This parse tree produces: aabb

Why CFG is More Powerful than Regular Grammar

Regular Language

Good for simple patterns.

a*b*

Can accept aaabbb, but also aabbb and abb.

Context-Free Language

Can enforce matching count and nesting.

aⁿbⁿ

Requires the same number of a’s and b’s.

Real-World Uses of CFG

Programming Languages

Syntax for if-statements, loops, expressions, blocks.

Compilers

Parsers use grammar to check if code is structurally correct.

Markup

Nested tags in HTML/XML can be modeled with CFG ideas.

Real-life thought: CFG is like the rulebook that checks whether code “looks grammatically correct.”

Example 2: Simple Arithmetic Expressions

E → E + E E → E * E E → (E) E → id

This grammar can generate:

idid + idid * id(id + id)

id means identifier, like x, y, total, score.

Leftmost and Rightmost Derivation

Leftmost Derivation

Always replace the leftmost variable first.

E ⇒ E+E ⇒ id+E ⇒ id+id

Rightmost Derivation

Always replace the rightmost variable first.

E ⇒ E+E ⇒ E+id ⇒ id+id

Both can generate the same string, but the replacement order is different.

Ambiguity in CFG

A grammar is ambiguous if one string can have more than one parse tree or meaning.

E → E + E | E * E | id

String: id + id * id

Meaning 1

(id + id) * id

Meaning 2

id + (id * id)

How to Reduce Ambiguity

We can separate grammar rules by priority or precedence.

E → E + T | T T → T * F | F F → (E) | id

Idea: Multiplication belongs to T, addition belongs to E. This helps force multiplication to be handled before addition.

Example 3: Balanced Parentheses

S → SS S → (S) S → ε

This can generate:

()(())()()(()())
Invalid examples: )(, (() , ())(. They are not properly balanced.

Common Mistakes

1. Confusing terminals and variables

Variables can be replaced. Terminals are final symbols.

2. Forgetting the stop rule

Without a stop rule like ε or terminal-only rule, derivation may never end.

3. Producing extra symbols

Check each rule carefully.

4. Assuming one grammar only

Many different CFGs can describe the same language.

Mini Language Example: Game Commands

C → move D | jump | attack | C ; C D → left | right | up | down

Valid strings:

jumpmove leftattack ; jumpmove up ; attack

Invalid strings: move, left move, attack move
