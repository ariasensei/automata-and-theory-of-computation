Part I

Introduction to theory of computation

Computation is the process of solving a problem using a sequence of instructions.

Input
Data or request given to the system
Processing
Rules and instructions are applied
Output
Result produced by the system

Real-world example: ATM Machine

Input: ATM card, PIN, withdrawal request
Processing: Verify PIN, check balance, validate amount
Output: Cash dispensed and receipt printed

Quick check

In a Google search, what counts as the input?

The words or phrase typed by the user into the search box.

Understanding computation helps computer scientists design better solutions and understand the power and limits of digital systems.

Build better software
Design efficient algorithms
Create AI systems
Improve cybersecurity
Develop compilers
Understand computing limits

Part II

Automata as abstract machines

Topic 3

What is an Automaton?

An automaton is a mathematical model of a machine. It is an abstract way to understand how systems process information.

Vending machine analogy

Waiting for money → Money inserted → Item selected → Dispense item

Key idea

Automata move from one state to another based on inputs.

Topic 4

States and Transitions

A system can be described by the states it can be in and the rules that move it between states.

Green
Yellow
Red

Traffic light cycle: Green → Yellow → Red → Green

Examples of state-based systems:

Elevators • Mobile interfaces • Video games • Network protocols • Login systems

Part III

Formal languages and recognition

In computing, a language is a set of valid strings built according to specific rules.

Alphabet
{a, b}
Possible strings
a, b, aa, ab, ba, bb
Rule-based
Only valid forms belong

Programming languages are formal languages

Correct: print("Hello")
Incorrect: print"Hello"

A machine recognizes a language if it can decide whether a string belongs to that language.

Email validation example

Valid: student@gmail.com
Invalid: studentgmail.com

Login authentication
QR code scanning
Form validation

Part IV

Applications and computational complexity

Compilers

Check syntax, structure, and grammar before translating source code.

Artificial Intelligence

Model decision-making and sequence processing in intelligent systems.

NLP

Recognize patterns in language for translation, grammar, and speech tools.

Cybersecurity

Detect suspicious patterns in spam, malware, and intrusions.

Search Engines

Use pattern matching to find relevant information quickly.

Computational Complexity

Studies how much time and memory a problem needs.

Why complexity matters

Finding one student name in a class of 10 is easy. Searching one profile among billions of users is much harder. Computational complexity helps us decide which solutions are efficient and which are impractical.

Companies like Google, Microsoft, and Meta invest heavily in efficient algorithms because even small improvements can save enormous computing resources.
