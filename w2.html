Part I

Mathematical foundations

A set is a well-defined collection of objects. The objects inside a set are called elements.

Realistic example

Let J be the set of students who ride a jeepney to school and B be the set of students who ride a bus. If Ana rides both, then Ana belongs to J ∩ B, the intersection of the two sets.

Union
A ∪ B = in A or B or both
Intersection
A ∩ B = in both A and B
Difference
A − B = in A but not in B

Quick check

If A = {1,2,3,4} and B = {3,4,5}, what is A ∩ B?

A ∩ B = {3,4}

A relation describes a connection between elements of two sets. A function is a special relation where each input has exactly one output.

Realistic example

Let each student be matched to one student number. This is a function because one student cannot have two official student numbers at the same time.

Relation:
{(Ana, Math), (Ben, English), (Cara, Math)}
Function:
student → student number

Quick check

Is “student → favorite subject” always a function?

Not always. If a student chooses more than one favorite subject, one input may have multiple outputs.

An alphabet is a finite set of symbols. A string is a finite sequence of symbols from that alphabet.

Realistic example

For a school ID code, if the alphabet is Σ = {0,1,2,...,9}, then 2026 is a string over Σ.

Alphabet
Σ = {a,b,c}
String
abca
Length
|abca| = 4

Quick check

If Σ = {0,1}, is 102 a string over Σ?

No. The symbol 2 is not in the alphabet {0,1}.

Part II

Logic: the language of reasoning

Topic 4

Propositional Logic

A proposition is a statement that is either true or false.

Example

p: “The classroom has a projector.”
q: “The class can show slides.”
p → q: If the classroom has a projector, then the class can show slides.

¬p means “not p”

p ∧ q means “p and q”

p ∨ q means “p or q”

p → q means “if p, then q”

Quick check

What is the negation of “The exam is difficult”?

“The exam is not difficult.”

Topic 5

Predicate Logic

Predicate logic extends propositional logic by using variables and quantifiers.

Example

Let P(x): “x submitted the assignment.”
∀x P(x) means “Every student submitted the assignment.”
∃x P(x) means “There exists a student who submitted the assignment.”

∀ = for all

∃ = there exists

Quick check

Translate: “Some student is absent.”

∃x A(x), where A(x): “x is absent.”

Part III

Proof techniques

Direct Proof

Start from the assumption and logically reach the conclusion.

Example: Prove that if n is even, then n² is even.
If n is even, n = 2k for some integer k.
Then n² = (2k)² = 4k² = 2(2k²), so n² is even.

Contrapositive Proof

To prove p → q, prove the equivalent statement ¬q → ¬p.

Example: To prove “if n² is odd, then n is odd,” prove:
If n is even, then n² is even.
Since the contrapositive is true, the original statement is true.

Proof by Contradiction

Assume the opposite of what you want to prove, then show that assumption leads to an impossibility.

Example: To prove √2 is irrational, assume √2 is rational.
This eventually gives a contradiction about even and odd numbers.

Mathematical Induction

Use two steps: prove the base case, then prove that if one case is true, the next case is also true.

Example: Prove 1 + 2 + ... + n = n(n+1)/2.
First prove n = 1. Then assume true for n = k and show true for k+1.

Practice and Apply

Learning activities

Group Activity

In groups of 4, create a “Campus Life Set Map.”

  1. Define three sets of students, such as students who commute, students who join clubs, and students who bring packed lunch.
  2. Draw a Venn diagram showing intersections.
  3. Create one relation and one function using your group members.
  4. Present one conclusion using a logical statement.
Output: 1 manila paper or 1 slide + 2-minute explanation

Individual Activity

Answer the following in your notebook.

  1. Let A = {1,2,3,4} and B = {2,4,6}. Find A ∪ B, A ∩ B, and A − B.
  2. Give one real-life example of a function.
  3. Negate the statement: “All students passed the quiz.”
  4. Identify the best proof method for: “If n is odd, then n² is odd.”
Reminder: Show complete reasoning, not just final answers.
